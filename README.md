# Tic Tac Toe

Ein modernes Tic Tac Toe-Spiel in HTML, CSS und JavaScript. Das Projekt ist als kleines Webspiel angelegt und kann lokal im Browser gestartet werden.

## 🎮 Spielbeschreibung

- Klassisches Tic Tac Toe mit 3x3-Feld
- Zwei Spieler wechseln sich ab: `X` und `O`
- Gewinner wird automatisch erkannt
- Bei Unentschieden wird das Feld gesperrt und ein Neustart ist möglich
- Animierte Anzeige für den aktiven Spieler
- Sauberes, dunkles Design mit Hover-Effekten

## 🚀 Dateien

- `index.html` – Hauptseite und Spiel-Oberfläche
- `style.css` – Styling für Layout, Spielbrett und Interaktion
- `script.js` – Spiel-Logik, Spielerwechsel, Gewinner-Prüfung und Reset
- `assets/` – enthaltene Icons und Bilddateien für das Projekt
- `scripts/template.js` – zusätzlich eingebundene Hilfsdatei

## 🧠 Technik

- Reines JavaScript ohne Frameworks
- HTML-Layout mit dynamischer Erzeugung des Spielbretts
- CSS für responsive Darstellung und Animationen
- Spielzustand wird lokal in einem Array verwaltet

## ▶️ So benutzt du das Spiel

1. Projektordner öffnen
2. `index.html` im Browser öffnen
3. Auf ein freies Feld klicken, um zu spielen
4. Nach einem Sieg oder Unentschieden auf `Noch einmal` klicken

## ✅ Funktionen

- Spielerwechsel nach jedem Zug
- Gewinnlinien-Erkennung für alle möglichen Kombinationen
- Neustart-Button nach Spielende
- Aktive Spieleranzeige mit visuellem Feedback

## 📌 Hinweis

Das Projekt ist ideal als Übung für Einsteiger in Webentwicklung. Es eignet sich besonders zum Lernen von DOM-Manipulation, Event-Handling und einfachem Spiel-Flow.
